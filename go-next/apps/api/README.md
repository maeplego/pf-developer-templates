## Run

```powershell
copy .env.example .env
$env:DEV_AUTH="true"
go test ./...
go run ./cmd/server
curl.exe http://localhost:{{HTTP_PORT}}/health
curl.exe http://localhost:{{HTTP_PORT}}/v1/products
```

Compose:

```powershell
docker compose -f deploy/compose.yaml up --build
```

## Env

| Variable | Role |
| --- | --- |
| `HTTP_PORT` | Listen port (default {{HTTP_PORT}}) |
| `DEV_AUTH` | P04/P06 header auth (`X-Dev-User-Sub`) |
| `OIDC_ISSUER` / `OIDC_INTERNAL_BASE` / `OIDC_AUDIENCE` | P01 client stub; userinfo when not in dev auth |
| `OTEL_EXPORTER_OTLP_ENDPOINT` | P02 collector (reserved; logged, not required to start) |
| `CORS_ORIGIN` | Browser origin |

Ops create: `POST /v1/ops/products` with `X-Dev-User-Sub` when `DEV_AUTH=true`.
